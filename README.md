# BLUE JEANS · HASIRA ANI ENGINE

HASIRA_yo! 유튜브 채널의 응원 쇼츠 자동 생산 엔진. 니들펠트 인형 캐릭터가 실사 배경 속에서 아주 느리게, 사소하지만 절실한 미션에 도전하는 30초 넌버벌 쇼츠를 시즌 100화로 만든다.
화면 구성·저장 방식은 [Shortform-Drama-Engine](https://github.com/cinepark-1974/Shortform-Drama-Engine) v1.1 을 따른다.

## v0.1 (2026-11-13)
- 화면 뼈대: 시즌 선택, 연결 상태, 대시보드(시즌 진행률 · 100화 진행판 · 지금 할 일), 단계 01~08.
- 01 출연진: 고정 출연진 10 · 빠른 아이 4 · 손님 2 의 기준 그림과 캐릭터 정보(표식 소품 · 성격 · 소리 · 기본 각도 · 외형 고정 영어 문장).
  - 앱 안에 2026-11-13 확정 기준 그림 17장(assets/cast) 포함. 드라이브 없이도 동작.
  - 구글 드라이브 HASIRA_ANIME 폴더에서 `번호_이름_표정` 규칙의 그림을 읽어 저장소로 가져오기.
  - 캐릭터마다 그림 직접 올리기 · 기본본으로 되돌리기. 저장소 그림이 기본본보다 우선.
- 02 시즌 설계 ~ 08 마스터: 자리만 있음.
